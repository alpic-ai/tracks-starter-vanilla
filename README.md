# Vanilla starter

A minimal web page in plain HTML, CSS and JavaScript, with no dependencies and no build step.

- `index.html`: the page
- `styles.css`: its styles
- `main.js`: its script, loaded as an ES module

## Run

Serve the folder with any static file server:

```sh
npx serve .
```

or

```sh
python3 -m http.server 3000
```
